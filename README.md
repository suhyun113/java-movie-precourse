## 추가 조건

- 상영관 운영
    - 하나의 영화관 내에서는 동일한 시간에 여러 상영을 진행할 수 없다.
    - 하나의 영화는 여러 영화관에서 동일한 시간에 상영할 수 있다.
    - 각 영화관에서는 같은 시간대에 같은 영화를 상영할 수 있다.
    - 하나의 영화관에서는 시간이 겹치지 않는 상영을 예매할 수 있다.
- 예매 규칙
    - 고객은 시간이 겹치는 여러 상영을 동시에 예매할 수 없다.
    - 한 사람이 동시에 여러 영화관에 존재할 수 없다는 제약을 반영한다.
- 상영 기간
    - 영화는 정해진 개봉일과 종영일 사이에만 상영될 수 있다.
    - 상영 시간은 영화관 운영 시간 안에 포함되어야 한다.
- 좌석 배치 및 등급
    - 좌석은 A부터 P까지 총 16행으로 구성한다.
    - 맨 앞 3줄은 B석으로 가격이 가장 저렴하다.
    - 맨 뒤 4줄은 S석으로 가격이 가장 비싸다.
    - 나머지 9줄은 A석으로 중간 가격을 적용한다.
- 할인 및 결제
    - 무비데이 할인과 시간대 할인이 적용된 후, 고객이 사용한 포인트를 차감한다.
    - 최종 금액에 대해 결제 수단에 따른 할인이 적용된다.
